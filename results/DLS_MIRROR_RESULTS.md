# DLS-style design (dls_rtl/) - measured results

Generated by `scripts/run_dls_mirror.py`. Design = VECTOR-REGISTER-FILE -> LANES x 8-Bit-ALU -> RESULT-REGISTER-FILE, 8-bit lanes, 3-bit opcode (6 operations).

## Tests

* Screenshot cases (6 ALU operations + full-chip vector subtract), exhaustive ALU (524,288 checks), equivalence with `rtl/lane_alu.v` (393,216 checks), 4,000-pass streaming test, enable-gating test: **all pass**.
