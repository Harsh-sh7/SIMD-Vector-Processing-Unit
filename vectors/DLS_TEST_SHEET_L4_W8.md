# DLS cross-check sheet: SIMD_4LANE (4 lanes x 8 bit)

For the Digital Logic Sim chip `SIMD_4LANE`. Set A0..A3 and B0..B3, put the opcode S2 S1 S0 on the low three bits of `IN` (the fourth bit is unused), pulse `LOAD-A` / `LOAD-B` with a clock, then `RESULT_WRITE` with a clock, and compare R0..R3 with the EXPECTED column.

Values are unsigned decimal, as the simulator displays them, listed lane 0 first (A0, A1, A2, A3). COMPARE gives 255 when the two lanes are equal and 0 otherwise. Opcodes 110 / 111 are unconnected.

The rows of the first table are tests from `vectors_L4_W8.mem`, which `make vectors` replays through the Verilog RTL (where COMPARE is the RTL operation EQ, code 9).
